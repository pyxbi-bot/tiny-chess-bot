Compact, high-performance chess engine in under 4 KB of Python for make.fun's tiny-chess-01 bounty.
Features Alpha-Beta search with negamax, piece-square positional tables (PST), MVV-LVA move ordering, and quiescence search.

## Run it

```sh
python3 -P -s main.py
```
